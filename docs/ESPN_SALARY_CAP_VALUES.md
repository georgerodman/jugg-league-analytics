# ESPN Salary Cap Values

The repository contains ESPN's published non-PPR Salary Cap Value cheat sheets
for the 2020–2026 preseasons. Each sheet states a 10-team league and a $200
budget per team. The values remain provider estimates and are never treated as
ESPN ADP or as a proprietary JUGG valuation.

Artifacts contain season, ranks, player, team, salary-cap value, bye week,
canonical internal ID, FantasyPros ID when available, identity status,
matching method/confidence, source path, and source checksum. The combined
validation report is the review queue for row-count, rank, salary-range,
ambiguous-identity, and unmatched-identity issues.

The current validated build contains 1,980 rows: 300 in 2020 and 280 in each
season from 2021 through 2026. Every row has a canonical or stable identity,
and the current validation report contains no flags.
